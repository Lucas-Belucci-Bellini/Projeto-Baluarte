## Resumo

A `v2.0.0-alpha.7` limita explicitamente o modo `verify:v2 --evidence`. O Doctor verifica o tamanho do arquivo antes do parse e aceita no máximo `256 KiB` e `100` registros antes da normalização. Entradas acima desses limites são rejeitadas, não truncadas nem parcialmente aceitas.

O objetivo é preservar a propriedade de diagnóstico bounded quando o Doctor recebe evidência externa ou previamente coletada. A mudança não altera o catálogo de checks, não instala dependências, não executa operações mutáveis e não transforma evidência incompleta em estado verde.

## Limites alpha

A V2.0.0 estável ainda não foi declarada. Esta release não altera o Event Bus, não cria retry, threshold, alerta, persistência, storage, banco, Supabase, RLS, tenancy, ownership, revisão humana server-side, Auth real, autoridade ou promoção operacional.

Os limites são de proteção contra entrada excessiva do Doctor, não de escala de produção. O modo `--evidence` continua exigindo JSON válido e a normalização continua aplicando seus próprios limites de texto e estados. O replay de evidência não prova que a fonte é atual, autêntica ou autorizada.

Neste sandbox, `npm run verify:v2` pode manter estado `unknown` para Cargo indisponível. Esse estado continua não-verde por design; somente a ausência exata do SDK opcional `google-genai` é classificada como `blocked-known` nos transportes Python declarados.

## Rollback

O rollback retorna ao commit anterior da `main` (`a35ca3f`, alpha.6) ou à branch de backup [`backup/2026-08-25-before-v2-doctor-evidence-bounds`](https://github.com/Lucas-Belucci-Bellini/Projeto-Baluarte/tree/backup/2026-08-25-before-v2-doctor-evidence-bounds). A reversão remove somente os limites de replay, seus testes e o ajuste documental, preservando a classificação ambiental do Doctor, o benchmark Event Bus, a V1 e releases anteriores.

## Próximos bloqueios

Continuam pendentes a política de retry por classe de evento, ownership/retenção/revisão humana server-side, persistência Supabase/RLS, Auth real, runtime Rust em toolchain compatível, performance em hardware de usuário e qualquer evidência externa confiável. Nenhum desses temas é inferido a partir do limite local de replay.
