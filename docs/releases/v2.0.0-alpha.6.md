## Resumo

A `v2.0.0-alpha.6` endurece o `verify:v2` para que a fotografia operacional não confunda uma dependência opcional ausente com uma regressão do produto. Os dois contratos de transporte Python que importam o backend opcional reconhecem a ausência exata do SDK `google-genai`, declarado em `backend/requirements.txt`, como `blocked-known` quando ele não está instalado no ambiente observado.

A correção é deliberadamente estreita. Falhas diferentes continuam `failed`, evidência indisponível continua `unknown`, e operações mutáveis continuam `not-run` quando o Doctor não pode executá-las de modo seguro. O benchmark do Event Bus permanece catalogado como observabilidade segura: verde significa que o instrumento executou e passou sua autoconsistência, não que uma meta de produção foi atingida.

## Leitura local do Doctor

Neste sandbox, `npm run verify:v2` deixa os dois transportes Python como `blocked-known` pela ausência do SDK opcional e mantém o runtime Rust como `unknown` porque Cargo não está disponível no ambiente. O Doctor retorna estado não-verde para esse `unknown`, conforme o contrato; isso é intencional e não foi mascarado.

O estado `blocked-known` também não é convertido em `green`. A diferença é que ele identifica uma limitação ambiental conhecida e documentada, enquanto `unknown` significa que a evidência não pode ser classificada com segurança.

## Limites alpha

A V2.0.0 estável ainda não foi declarada. Esta release não instala dependências, não muda `requirements.txt`, não executa o backend Python, não altera o Event Bus, não cria retry, threshold de latência, persistência, Supabase, RLS, tenancy, ownership, revisão humana server-side, Auth real, autoridade ou promoção operacional.

O `verify:v2` continua não substituindo o runner oficial. Build, harness, smoke, caminho crítico e compilação Python permanecem classificados conforme a política de mutação do Doctor, e CI remoto continua exigindo evidência própria.

## Rollback

O rollback retorna ao commit anterior da `main` (`9926276`, alpha.5) ou à branch de backup [`backup/2026-08-25-before-v2-doctor-env-fix`](https://github.com/Lucas-Belucci-Bellini/Projeto-Baluarte/tree/backup/2026-08-25-before-v2-doctor-env-fix). A reversão remove apenas a classificação específica, os testes e o ajuste documental do Doctor, preservando benchmark, Event Bus, V1 e releases anteriores.

## Próximos bloqueios

Continuam pendentes a política de retry por classe de evento, ownership/retenção/revisão humana server-side, persistência Supabase/RLS, Auth real, runtime Rust em toolchain compatível e evidências de performance em hardware de usuário. Nenhum desses temas será inferido a partir da classificação ambiental desta alpha.
