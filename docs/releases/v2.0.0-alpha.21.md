# Baluarte V2 — `v2.0.0-alpha.21`

**Status:** prerelease bounded; publicação versionada somente após o gate final
**Data:** 2026-08-27
**Marco:** hardening bounded de lifecycle, contexto de eventos e restart concorrente

## Resumo

A alpha.21 candidata reúne três slices pequenas do Core/Module System executadas depois da alpha.20. A PR #517 corrige o encerramento de módulos para `stop → Runtime.close → dispose`. A PR #518 preserva metadados autorizados do envelope através de `ctx.bus.emit`. A PR #523 adiciona single-flight por módulo ao helper `criarRuntimeRestart()`, impedindo que chamadas concorrentes do mesmo módulo sobreponham `stop → sleep → start`.

As três mudanças permanecem locais, in-memory e bounded. A #523 não altera o orçamento nem o backoff existentes, não muda a API de injeção do `RuntimeManager` e permite concorrência independente para módulos diferentes. Nenhuma delas liga automaticamente o restart ao boot ou transforma diagnóstico em autoridade operacional.

## Segurança, limites e fora do escopo

O single-flight é uma deduplicação in-memory por instância do helper. Ele não é lock distribuído e não coordena processos, abas, máquinas ou múltiplas instâncias. Não foram adicionados retry automático, política por classe de erro, persistência de incidentes, fila remota, dashboard, métrica remota ou autoridade server-side.

A candidata não fecha Module System, persistência, backup/restore operacional, Auth/RBAC server-side, RLS, tenancy, ownership, retenção, billing, Knowledge Mesh, Risk Engine, OpenClaw, Hermes, MCP externo, observabilidade persistente, aceite físico desktop/mobile, assinatura, auto-update, beta, RC ou V2 estável. A V1, router, shell, sidebar, wrappers, Service Worker, launcher normal, #501 e #471 permanecem preservados e separados.

## Rollback

O rollback é um `git revert` normal do squash merge correspondente, conforme o escopo: `f62ece73` para lifecycle, `9ca94781` para metadata de contexto ou `25cbc9f3` para single-flight, preservando os pais históricos. As branches de backup acima são referências de baseline pré-merge desta sequência; não devem ser sobrescritas. Não há migration nem dado persistente para restaurar.
