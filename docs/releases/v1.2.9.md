## Escopo

A release 1.2.9 continua o marco Wiki Zomboid/Evidence da V2. O resumo da API do módulo passa a expor apenas contagens bounded por status (`pending`, `verified`, `rejected` e `superseded`). A view V2 informa quantidade de evidências vinculadas e pendentes sem expor statements, fontes, claims, tokens ou autoridade.

O gate browser prova que a API é resolvida pelo Registry, que o boot limpo começa com zero evidências vinculadas e que a superfície exibe `0 vinculadas · 0 pendentes`. O teste focal também comprova que uma anexação local `pending` atualiza a contagem por status no store compartilhado.

## Segurança e limites

Esta é uma extensão local/read-only de observabilidade. Não adiciona permissões, storage, rede, scraping, persistência, Auth, RLS, Supabase, OpenClaw, WhatsApp ou ações externas. Não existe botão de aprovação e nenhum status é alterado pela view. A futura revisão humana exige autoridade server-side, auditoria e política de tenancy; não é criada neste release.

A V1, o router, as 99 rotas do smoke, as superfícies `/zomboid` e `/zomboid-admin` e os wrappers JavaScript permanecem preservados. `runtimeAuthority` continua `not-authorized` e `publicPromotionAllowed` continua `false`.
