# Baluarte V2 — `v2.0.0-alpha.18`

**Status:** pré-release técnica documentada; publicação condicionada à tag

**Data:** 2026-08-26

**Marco:** Runtime desktop empacotado com prova de `process.resourcesPath`

## Resumo

A alpha.18 adiciona um gate real para a principal lacuna prática restante do Runtime desktop: executar o Runtime Rust dentro de um artefato Electron empacotado, usando a configuração real de `desktop/package.json` e os recursos copiados para `resources/`.

O smoke constrói o bundle web, compila o Runtime Rust em release, gera um diretório `linux-unpacked` temporário, executa o app sob Xvfb e confirma a cadeia `Electron empacotado → process.resourcesPath → transporte ESM → processo Rust`. Em seguida, autoriza um módulo sintético, lê um arquivo dentro da raiz confinada e confirma que `../` é recusado.

## Segurança e não-escopo

O smoke não cria autoridade server-side, não altera Auth, JWT, claims, Supabase, SQL, migration, RLS, tenancy, ownership, persistência, rede, retry, fila ou IPC. Não aceita override de `BALUARTE_RUNTIME_BIN`, pois a finalidade desta slice é provar `process.resourcesPath`. O build usa saída temporária e `--publish never`; nenhum instalador público foi gerado.

A V1, o router, a sidebar, os wrappers, o Service Worker, o Event Bus, Storage, Evidence e o launcher normal foram preservados. A alpha.18 não constitui aceite físico de Windows/macOS, assinatura de código, NSIS, DMG, AppImage instalado, auto-update, OAuth, câmera, microfone ou Runtime como autoridade de produção.

A PR #501 de privacidade continua OPEN/DRAFT e isolada. A PR #471 do Claude Code continua OPEN/DRAFT e intocada.
