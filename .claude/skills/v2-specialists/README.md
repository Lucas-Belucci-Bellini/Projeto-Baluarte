# V2 Specialists

Use a specialist by responsibility instead of treating the repository as one language.

- `javascript.md` — JS/V2-JSDoc specialist
- `rust.md` — Rust Runtime specialist
- `python.md` — Python/data specialist
- `sql.md` — SQL/Supabase specialist

A specialist diagnoses and fixes only its own layer. It must not weaken another layer's gate to make CI green.
