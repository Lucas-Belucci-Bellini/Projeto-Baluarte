# 📁 Projetos — Projeto Baluarte

Cada coisa construída com o **Claude Code** ganha a sua **pasta única** aqui
(`projetos/<nome-do-projeto>/`), com o que for específico daquele projeto
(notas, protótipos, dados, docs).

A página **/projetos** do site lista o índice (`src/data/projetos.json`).

## Convenção
- Um diretório por projeto: `projetos/meu-projeto/`.
- Um `README.md` curto dentro de cada pasta explicando o que é.
- Registrar o projeto em `src/data/projetos.json` para aparecer no site.

> Esta pasta é o "caderno de obras" — o histórico de alterações fica em
> `historico/CHANGELOG.md`.
